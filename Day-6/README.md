## Findings Summary

The job listings dataset contains **100 job records** with information about job titles, companies, locations, skills, salary, and URLs. The analysis was performed using SQLite, pandas, and matplotlib.

The first chart shows the **most in-demand skills** in the dataset. Flask appears most frequently with **8 job listings**, followed by CSS with **7**, Java with **6**, and Python and HTML with **5 listings each**. Django appears in **4 listings**. This suggests that web development technologies, particularly Flask, CSS, Java, Python, and HTML, are common skills in the collected job postings.

The second chart shows the **distribution of jobs by location**. The listings are spread across many different locations rather than being concentrated in one place. In the top results, each location has only **one listing**, showing that the dataset contains a wide variety of locations. Therefore, there is no single dominant location in this sample.

The third chart shows the **companies with the most job listings**. Garcia PLC has the highest number with **2 listings**, while the other companies shown have **1 listing each**. This indicates that the dataset is also widely distributed across different employers rather than being dominated by a small number of companies.

Overall, the analysis shows that **technical skills have clearer patterns than locations or companies** in this dataset. Flask is the most frequently appearing skill, while jobs and employers are distributed across many different categories. Salary information was not available in the collected records, so salary-based comparisons were not included in the analysis.
