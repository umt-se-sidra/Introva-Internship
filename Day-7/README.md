## Practice

### What Makes a Problem an ML Problem?

A problem is suitable for Machine Learning when we want a computer to learn patterns from data and use those patterns to make predictions or decisions instead of writing a separate rule for every possible situation. For example, an ML model can learn from previous house prices and their features to predict the price of a new house. The problem should have relevant data, a clear objective, and a way to evaluate how well the model performs.

### Batch Learning vs Online Learning

Batch learning is a method in which a machine learning model is trained on a complete dataset at once. If new data becomes available, the model generally needs to be trained again to learn from it. Online learning, on the other hand, allows a model to learn gradually from new data, either one example at a time or in small groups. Batch learning is useful when data is relatively stable, while online learning is useful when data changes frequently and the model needs to adapt.
