# Day 3 — Selenium: Dynamic Pages

## Objective

Learn browser automation with Selenium and use it to scrape content that is loaded dynamically using JavaScript.

## Tasks Completed

* Learned how to automate a browser using Selenium.
* Practiced locating elements on a web page.
* Used Selenium to click buttons and interact with page elements.
* Learned how to use explicit waits instead of relying on fixed delays.
* Worked with JavaScript-rendered content.
* Practiced scraping pages with dynamically loaded items.
* Handled the Load More functionality.
* Collected items repeatedly until all available content was loaded.

## Build

Built a Selenium scraper that interacts with a dynamic web page, waits for content to become available, and continues clicking/loading content until all required items are collected.

## Outcome

Learned how to automate a real browser with Selenium and reliably extract content from JavaScript-rendered pages using explicit waits.
