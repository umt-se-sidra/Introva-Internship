# Day 11 — Regression in Machine Learning

## Overview

This day focuses on understanding regression algorithms and implementing linear and Ridge regression using Python.

## Topics Covered

* Simple Linear Regression from scratch
* Multiple Linear Regression
* Ridge Regression
* Ridge Regression with different alpha values
* Gradient Descent
* Implementation of regression models using Python and Scikit-learn

## Practical Work

* Implemented Simple Linear Regression from scratch.
* Practiced Multiple Linear Regression using a dataset.
* Implemented Ridge Regression using Scikit-learn and a custom approach.
* Compared Ridge Regression models using different alpha values.
* Practiced gradient descent for model training.

## Tools and Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn
* Jupyter Notebook

## Learning Outcome

Learned how linear and Ridge regression work and practiced implementing and comparing regression models using Python.
