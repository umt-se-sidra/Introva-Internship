# Day 4: Feature Engineering II — Missing Data, Outliers & Dimensionality Reduction

## Overview

On Day 4 of my Introva internship, I studied different techniques for handling missing data, detecting outliers, and reducing the dimensionality of a dataset. I focused on understanding how data preprocessing affects machine learning and how to prepare a dataset before applying a model.

I also practiced KNN imputation and Principal Component Analysis (PCA) using Python and scikit-learn.

## Topics Covered

### 1. Handling Missing Data

Learned about different approaches to handling missing values, including:

* Complete Case Analysis
* Simple Imputation
* Handling missing numerical and categorical values
* Missing Indicator
* Random Sample Imputation
* KNN Imputer
* Iterative Imputer

### 2. Outlier Detection and Handling

Studied different methods for identifying and handling outliers:

* Z-score method
* Interquartile Range (IQR) method
* Percentile method
* Winsorization

These methods help identify unusually high or low values and determine how they should be handled during data preprocessing.

### 3. Feature Construction and Splitting

Explored how existing features can be transformed or divided into more useful features for machine learning.

### 4. Curse of Dimensionality

Learned how increasing the number of features can make data analysis and machine learning more challenging, and why dimensionality reduction can be useful.

### 5. Principal Component Analysis (PCA)

Studied PCA as a dimensionality-reduction technique.

The main concepts included:

* Understanding the geometric intuition behind PCA.
* Understanding the mathematical formulation of PCA.
* Reducing the number of dimensions while retaining important information.
* Applying PCA using scikit-learn.
* Visualizing data after dimensionality reduction.

## Practical Work

### PCA and Data Preprocessing

I practiced data preprocessing and dimensionality reduction using Python and scikit-learn.

My practical work included KNN imputation for handling missing values and applying PCA to transform the data into a lower-dimensional representation.

The notebook contains the implementation and results of the practical work.
